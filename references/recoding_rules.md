# Recoding Rules

## 1. SadOrHopeless
- Success = code 1
- Failure = code 2
- Other values or missing values were excluded from the proportion analysis.

## 2. HowTallAreYouWithoutShoesInMeters
- Missing values were removed.
- Only values between 1.0 and 2.5 meters were kept for analysis.
- Values outside this range were treated as invalid and excluded.
