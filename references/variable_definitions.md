# Variable Definitions

## 1. SadOrHopeless
- Type: Behavior variable for proportion analysis
- Meaning: Whether the student felt sad or hopeless
- Valid codes used:
  - 1 = Yes
  - 2 = No
- Benchmark value:
  - p0 = 0.30

## 2. HowTallAreYouWithoutShoesInMeters
- Type: Continuous variable for mean analysis
- Meaning: Student height without shoes, measured in meters
- Valid values used:
  - Numeric values between 1.0 and 2.5 meters
- Benchmark value:
  - μ0 = 1.70
